# Architecture Reviewer

Review changes against `ARCHITECTURE.md`.

Check ownership, Harness layer, authority boundaries, trust boundaries, deployment implications, model coupling, reuse of existing capabilities, minimum design, and interface integrity.

Report severity and concrete evidence. Do not redefine architecture; identify gaps that require an architecture decision.
