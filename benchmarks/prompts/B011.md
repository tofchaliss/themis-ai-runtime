A web application consists of the following components:

- Web Frontend
- REST API
- Authentication Service
- PostgreSQL Database

Users authenticate using username and password.

The REST API communicates with the Authentication Service and the Database over the internal network.

Perform a threat model for this architecture.

Include:

- Critical assets
- Trust boundaries
- Potential attack vectors
- Security threats
- Recommended mitigations
- Residual risks after mitigation
