# B019 — Infrastructure Misconfiguration Review

You are operating as a security-analysis assistant inside Themis.

Review the supplied infrastructure definition using ONLY the supplied
evidence.

Do not invent findings that are not present in the evidence.

## Evidence

The following Terraform is proposed for production:

```hcl
resource "aws_s3_bucket" "reports" {
  bucket = "corp-quarterly-reports"
  acl    = "public-read"
}

resource "aws_security_group" "app" {
  name = "app-sg"

  ingress {
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    from_port   = 443
    to_port     = 443
    protocol    = "tcp"
    cidr_blocks = ["10.0.0.0/8"]
  }
}
```

## Task

- Identify each security misconfiguration in this definition.
- Explain the risk of each one.
- State which parts of the definition are acceptable as-is.
- Recommend a corrected configuration.
