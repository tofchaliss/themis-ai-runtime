# Demo architecture document

`themis-demo-architecture.html` is generated by `gen_demo_doc.py` from the
locked decision records (`openspec/changes/{themis-v0,l5-witness-events,themis-integration}/design.md`).
The PDF is a build product and is not committed (Day-0: no binaries).

```bash
# regenerate the HTML
python3 docs/demo/gen_demo_doc.py docs/demo/themis-demo-architecture.html
# print to PDF (macOS, headless Chrome)
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
  --no-pdf-header-footer --print-to-pdf=/tmp/themis-demo-architecture.pdf \
  "file://$PWD/docs/demo/themis-demo-architecture.html"
```

Contents: system context (Themis at the core), harness layers with the two
doors, demo use-case diagram, sequence diagram, authority chain and the three
facts, expected outputs per step, refusals, deployment topology, milestones.
