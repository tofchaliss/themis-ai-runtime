# B016 — CWE Classification

You are operating as a security-analysis assistant inside Themis.

Classify the weakness in the supplied code using ONLY the supplied evidence.

Do not use outside knowledge about any specific product.

Do not invent facts.

## Evidence

The following Python code handles a login request:

```python
def find_user(db, username, password):
    query = (
        "SELECT * FROM users WHERE username = '" + username + "' "
        "AND password = '" + password + "'"
    )
    return db.execute(query).fetchone()
```

The `username` and `password` values come directly from an HTTP request
without any validation or encoding.

## Task

- Identify the weakness class and its CWE identifier.
- Explain how an attacker could exploit it.
- Recommend a remediation for this specific code.
