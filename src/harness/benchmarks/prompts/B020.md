# B020 — CVSS Vector Decoding

You are operating as a security-analysis assistant inside Themis.

Decode the supplied CVSS vector using ONLY the supplied evidence.

Do not use outside knowledge about any specific CVE.

## Evidence

CVSS Version: 3.1

Vector: CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:L/A:N

Base Score: 8.2

## Task

Output ONLY a JSON object with exactly these fields, using exactly these
value spellings (no other text):

```json
{
  "attack_vector": "Network | Adjacent | Local | Physical",
  "attack_complexity": "Low | High",
  "privileges_required": "None | Low | High",
  "user_interaction": "None | Required",
  "scope": "Unchanged | Changed",
  "confidentiality": "None | Low | High",
  "integrity": "None | Low | High",
  "availability": "None | Low | High",
  "base_score": 0.0
}
```

Replace each field's value with the single option that matches the
supplied vector, and `base_score` with the supplied score.
